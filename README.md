# 🍝 Recipe Card Page

A responsive recipe card webpage built using **HTML5 and CSS3**. The page presents a complete recipe with a food image, ingredients, cooking information, and step-by-step preparation instructions.

## 📌 Project Overview

The **Recipe Card Page** is a simple web development project designed to practice semantic HTML structure and CSS card styling.

The recipe card includes:

* Recipe image
* Recipe title and description
* Cooking time
* Number of servings
* Difficulty level
* Ingredients list
* Numbered preparation steps
* Responsive design for desktop, tablet, and mobile devices

## 🎯 Objective

The main objective of this project is to practice:

* Semantic HTML5 elements
* HTML unordered and ordered lists
* `figure` and `figcaption`
* CSS box model
* CSS Grid
* Responsive web design
* Card-based UI design
* Consistent spacing and typography

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

No JavaScript or external framework is required.

## ✨ Features

### 1. Responsive Recipe Card

The recipe card automatically adjusts to different screen sizes.

### 2. Semantic HTML

Semantic elements such as:

```html
<main>
<article>
<header>
<section>
<figure>
<figcaption>
<footer>
```

are used to create a meaningful page structure.

### 3. Ingredients List

Ingredients are displayed using an unordered list:

```html
<ul>
    <li>200 g pasta</li>
    <li>2 tablespoons butter</li>
    <li>4 cloves garlic</li>
</ul>
```

### 4. Preparation Steps

Preparation instructions are displayed using an ordered list:

```html
<ol>
    <li>Boil the pasta.</li>
    <li>Prepare the sauce.</li>
    <li>Mix the pasta with the sauce.</li>
</ol>
```

### 5. Figure and Caption

The recipe image uses semantic HTML:

```html
<figure>
    <img src="..." alt="Creamy pasta">
    <figcaption>Delicious Creamy Garlic Pasta</figcaption>
</figure>
```

### 6. Mobile Friendly

Media queries are used to make the page comfortable to view on:

* Desktop
* Laptop
* Tablet
* Mobile phones

Alternatively, open the folder in **Visual Studio Code** and use the **Live Server** extension.
